# PetClass 통합·검증 기록

## 운영 규칙

기존 학생 UUID와 `point_entries` 원장을 그대로 사용합니다. 첫 펫 무료, 서로 다른 종 최대 3마리. Lv.10·20에 이름과 모습이 바뀌며 최고 레벨은 30입니다. 기술은 진화 시 자동 습득합니다. 전투·기술 카드 상점은 이번 범위에 포함하지 않습니다.

| 타입 | Lv.1 | Lv.10 | Lv.20 | 외형 변화 |
|---|---|---|---|---|
| 잎 | 새싹이 | 잎새랑 | 수림호 | 아기 여우 → 두 꼬리 여우 → 가지뿔·세 꼬리 숲 수호자 |
| 물 | 방울핀 | 물결핀 | 피오레 | 방울 펭귄 → 물결 날개 → 파도 망토의 황제 펭귄 |
| 불 | 불꼬리 | 홍염랑 | 부랑 | 도롱뇽 → 날렵한 화염형 → 날개 달린 태양 수호룡 |
| 바람 | 솔비 | 풍다람 | 솔바람 | 작은 다람쥐 → 활공막 → 커다란 연 모양 날개 |
| 흙 | 조약콩 | 바위굴 | 맥 | 조약돌 두더지 → 바위 갑옷 → 산등성이 등껍질 |
| 빛 | 반디솜 | 빛나래 | 휘여명 | 작은 반딧나방 → 넓은 날개 → 여섯 날개 수호자 |

먹이 초기 가격은 30/80/200P, 경험치 30/90/240입니다. 초대권은 1,000P입니다. 구매 즉시 보관함에 지급되며 동일 아이템은 모아서 표시합니다. 구매 전 잔액, 사용 후 예상 레벨·진화를 확인합니다. 선택한 펫을 유지하고 반복 클릭을 차단합니다.

교사는 포인트 지급·차감, 특별 아이템 지급, 레벨 정정, 미사용 구매분 환불을 처리합니다. 포인트 상세는 본인·교사에게만 보입니다. 공용 기기의 학생 전환과 교사 잠금 버튼을 제공합니다.

## 데이터 보호

브라우저 → 같은 출처 `/api/farm` → 서버 키로 보호한 `petclass_gateway` 흐름입니다. DB에는 서버 키 해시만 저장합니다. 세션은 HttpOnly 쿠키·2시간 만료이며 학생 코드 변경 시 무효화됩니다. 새 테이블은 비공개 스키마에 있고 RLS로 직접 접근을 거부합니다.

학생 행 잠금 안에서 잔액 검사·차감·지급·주문 저장을 함께 수행합니다. 요청 ID 재전송으로 중복 결제하지 않습니다. 펫 변경은 버전 비교로 동시 작업 덮어쓰기를 막습니다. 환불은 미사용분만 당시 가격으로 처리합니다. 구매 원장의 직접 수정·삭제는 차단합니다.

옛 사이트 공개 포인트 기록도 숨겼으며 옛 구매 RPC의 펫 상품 결제를 막았습니다. 운영 주소 전환 후 기존 RPC의 브라우저 직접 실행 권한도 회수했습니다. 내부 교사 기능은 보호된 gateway를 통해 그대로 호출합니다. Supabase 보안 검사에는 의도된 테이블 직접 접근 차단과 키로 보호한 gateway의 SECURITY DEFINER 실행 허용 안내만 남습니다. [검사 설명](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable).

새 투명 PNG 22개와 WebP 22개를 만들었습니다. `assets/generated-manifest.json`에 대응 경로가 있습니다. `assets/prompts.json`은 보존된 생성 프롬프트 일부이며 전체 디자인 기준은 위 표입니다. PNG 원본과 학생 데이터 백업은 Git에서 제외합니다.

기존 classroom-rule-system 최신 커밋 `317352f7cce266e00c18928b7bdc17f3c0989afb`에서 시작했습니다. ClassFarm 원본 소스는 `2d73725` 커밋의 `legacy-classfarm/`에서 복구할 수 있습니다. 실행 폴더에서는 중복 앱·미사용 D1 예제를 제거했습니다.

## 검증 범위

- 단위 검사: 22개 에셋, 18개 이름, 진화 경계·최고 레벨, 펫 소유권, 최대 보유 수, 먹이 수량, 요청 출처·크기.
- `tests/database.sql`: 실제 Supabase 트랜잭션에서 구매·재전송·가격 위조·잔액 부족·환불·권한·버전 충돌·로그아웃 검사 후 전부 롤백.
- 실제 학생 코드 HTTP 로그인, 구매 확인의 잔액 계산, 역할·상담 연동. 실제 학생의 결제는 실행하지 않음.
- 데스크톱·390px 모바일에서 이미지·가로 넘침·기본 접근성 확인. 성장·교사 화면은 합성 데이터로 별도 확인.
- 전환 전후 학생 25명, 포인트 기록 37건, 학생 잔액 합계 45,300P 일치.

실제 교실 장기 사용성 및 동시 부하 시험은 별도입니다. 운영 데이터 초기화는 수행하지 않았습니다.

## 배포

2026-10-01 기존 운영 주소 https://classroom-rule-system.vercel.app 에 교체 배포했습니다. 배포 ID: `dpl_2LWcskn4GfKUyNrTz6qbiCesXPa1`, 상태 READY, 빌드 약 25초. `tests/deployed-smoke.mjs`로 운영 API를 다시 검사할 수 있습니다. 학생 코드 입력은 환경 변수 `PETCLASS_SMOKE_CODE` 또는 비공개 로컬 백업을 사용하며 출력하지 않습니다.

롤백 시 옛 배포만 되돌리면 직접 RPC 권한 회수 때문에 정상 동작하지 않습니다. 기존 RPC 권한을 검토해 복원하거나 통합본의 수정 배포를 사용해야 합니다.

외부 API에서 내부 `commit`·`request`·`legacy` 명령을 전달할 수 없도록 허용 목록을 적용하고 단위·운영 검사에 포함했습니다.
